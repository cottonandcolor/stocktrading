The story

Advisor day, with guardrails

Open Jane’s book → clear KYC → research markets → recommend → approve → act. If KYC expires mid-flow, advice blocks and NotificationAgent remediates.

Coordination

One agent, role-based tools

TrueForge runs finguard-kyc-advisor. “Sub-agents” are roles stamped on MCP tool calls + audit — the supervisor routes work by calling the right tools in order.

MarketData Live Yahoo Finance

Coordination under failure

When KYC expires mid-day

KycAgent · simulate_kyc_expiration → AdvisorAgent · recommend → BLOCK → NotificationAgent · notify_kyc_expired → DeskAgent · task + Slack

What the UI shows

  • Day path jumps to Compliance
  • Advise / Act visually blocked
  • Client notify + form link appear on desk

Why it matters

Agents don’t improvise past policy — MCP returns ACTION BLOCKED, then NotificationAgent remediates with a renewal form (demo SMTP).

Close the day

Act — restore, trade, follow up

Restore

Closes remediation tasks on the desk.

Destructive tool → TrueForge approval → simulated fill (no broker).
